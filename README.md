# PDF Summarizer

An AI-powered tool that automatically summarizes PDF documents and exports the summary as a downloadable PDF.

## What it does
- Upload any PDF document
- AI reads and analyzes the content
- Generates a concise, readable summary
- Automatically exports the summary as a new PDF for download

## Tech Stack
- Python
- PDF processing library
- Reportlab
- OpenAI API for summarization

## How to use
1. Upload your PDF file
2. Wait for the AI to process and summarize
3. Automatic download for the generated summary PDF
